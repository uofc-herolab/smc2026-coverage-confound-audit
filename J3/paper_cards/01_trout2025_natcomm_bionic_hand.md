# Paper Card — trout2025_natcomm_bionic_hand

## Full citation (APA)
- Trout, M. A., Mino, F. R., Olsen, C. D., Hansen, T. C., Teramoto, M., Warren, D. J., Segil, J. L., & George, J. A. (2025). Shared human-machine control of an intelligent bionic hand improves grasping and decreases cognitive burden for transradial amputees. *Nature Communications, 16*(1), 10418.

## Link / DOI
- https://doi.org/10.1038/s41467-025-65965-9

## Problem (1–3 sentences)
- Prosthetic hands can be mechanically advanced but still impose high cognitive burden and low usability due to limited control interfaces.
- Shared autonomy can improve performance and reduce burden, but must be evaluated carefully for user experience outcomes.

## Approach (what they did)
- Shared human–machine control: user provides high-level intent via sEMG while the prosthesis provides finger-level “reflex-like” adjustments using integrated sensing (e.g., proximity/pressure).

## Setup / Participants / Data
- n, population: 4 transradial amputees + intact-limb cohort (paper reports ~9–13 depending on task; verify per task).
- tasks: fragile-object transfer, sustained hold task (ball-holding), functional activity tasks (e.g., drinking).
- apparatus: modified commercial bionic hand (reported TASKA-based) with sensorized fingertips and sEMG acquisition.

## Measures (what they measured)
- Performance: success rates, failures/drops, hold time, peak grasp forces.
- Workload: NASA-TLX.
- Objective cognitive burden: vibrotactile Detection Response Task (DRT) response times.
- Effort/physiology: muscle activation proxies (e.g., MAV).

## Key results (include numbers)
- Success improved under shared control in transfer task (reported p = 0.004) and holding task (reported p = 0.039).
- Workload reduced: NASA-TLX significantly lower with assistance (reported p < 0.001).
- Cognitive burden reduced: DRT RT improved (reported p = 0.016).
- Peak forces reduced under shared control (reported p < 0.001).

## Limitations / failure modes
- Controlled lab environment; unknown real-world generalization.
- Assistance appears largely static (not workload-adaptive).
- Task set does not include complex multi-step dexterous sequences.

## What we reuse (for J3)
- Evaluation strategy: use convergent workload evidence (NASA-TLX + objective workload metric).
- Benchmark framing: shared control can reduce burden and improve outcomes.
- Report both performance and force/effort proxies, not performance alone.

## What we must NOT repeat (avoid redundancy vs C3/C1/C2)
- Avoid static assistance as the endpoint; J3 advances to workload-adaptive τ(t).
- Don’t infer agency from performance/workload alone; J3 measures agency directly and validates ALI ↔ SoA.
